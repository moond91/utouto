최종 업데이트: 2026년 9월

우토우토(이하 "본 프로그램")은 대본으로 그림·목소리·자막·영상을 만드는 Windows 데스크톱 프로그램입니다. 본 방침은 본 프로그램이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 수집하는 정보

본 프로그램은 사용 승인(로그인) 목적으로만 아래 정보를 처리합니다.

항목언제
구글 계정의 이메일 주소·이름구글 계정으로 로그인할 때
신청 시 입력한 성함·닉네임·강의명처음 사용 신청할 때
기기 식별값(컴퓨터 부품 정보로 만든 고유 번호)·컴퓨터 이름·접속 시각·프로그램 버전로그인·사용 중

기기 식별값은 컴퓨터 부품 정보를 되돌릴 수 없게 변환(해시)한 값이며, 원래 정보를 알 수 없습니다. 한 계정으로 쓸 수 있는 컴퓨터 수를 제한하기 위한 것입니다.

2. 이용 목적

  • 사용 승인 및 이용 기간 관리
  • 한 계정당 등록 컴퓨터 수 제한(무단 공유 방지)
  • 새 신청·비정상 접속 시 관리자 알림

3. 저장 위치와 보관

  • 위 승인 정보는 관리자의 구글 스프레드시트에 저장되며, 새 신청·기기 한도 초과 시 관리자에게 알림(텔레그램)이 전송됩니다.
  • 로그인 상태는 본인 컴퓨터에만 암호화되어 저장됩니다.
  • 이용을 중단하고 삭제를 원하시면 아래 문의처로 요청해 주세요. 해당 정보를 삭제해 드립니다.

4. 컴퓨터에만 저장되고 외부로 보내지 않는 정보

  • 사용자가 넣은 API 키는 본인 컴퓨터에만 운영체제 암호화로 저장되며, 본 프로그램의 승인 서버로 전송되지 않습니다.
  • 사용자가 입력한 대본과 만들어진 그림·영상·음성은 본인 컴퓨터에만 저장되며, 본 프로그램의 승인 서버로 전송되지 않습니다.

5. 제3자 서비스

본 프로그램은 사용자가 고른 기능에 따라 아래 외부 서비스를 이용합니다. 각 서비스에 전송되는 정보는 해당 서비스의 개인정보처리방침을 따릅니다.

  • Google — 로그인(계정 확인), 그리고 사용자가 구글 기능을 쓸 때 그림·영상·글 생성 요청
  • 사용자가 직접 API 키를 넣어 쓰는 유료 AI 서비스(예: ElevenLabs·Typecast·MiniMax 등) — 그 기능을 쓸 때만 해당 서비스로 요청이 전송됩니다.

구글 로그인으로 받는 정보는 이메일·이름뿐이며, 이메일·연락처·문서 등 다른 구글 데이터에는 접근하지 않습니다.

6. 변경 사항

본 방침은 변경될 수 있으며, 변경 시 본 페이지에서 업데이트됩니다.
